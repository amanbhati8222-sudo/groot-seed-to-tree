## Project

GROOT — From Seed to Tree

## Concept

A Marvel-inspired event experience representing a student's growth journey:

Seed → Sprout → Sapling → Tree

## Tech Stack - 

HTML
CSS
JavaScript
GitHub Pages

## Features - 

Cinematic Groot hero
Responsive design
Growth Mode interaction
Scroll animations
Event timeline
Registration modal
Form validation
Mobile responsive layout

## Deployment- https://amanbhati8222-sudo.github.io/groot-seed-to-tree/

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Structure
- `index.html` — complete page + registration modal
- `style.css` — responsive visual system and animations
- `script.js` — modal, mobile menu, scroll reveal and Growth Mode interaction
- `assets/` — supplied Groot reference assets

## Notes
- Registration is intentionally a front-end demo: it validates the fields and shows a success state but does not send data to a server.
- Event details are kept as requested: Date — To Be Announced, Venue — Bennett University, Time — TBA.
- The design uses a Groot-inspired visual direction and does not claim official Marvel affiliation.
